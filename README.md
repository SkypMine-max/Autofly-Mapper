# Autofly-Mapper
A small client-side Fabric mod for Minecraft 26.1.2(needs fabric api 0.155.3+26.1.2).  Pick two corners and it walks a "lawnmower" sweep over the whole rectangle between them. useful for large map downloads, Needs Elytra Fly to works
