# Autofly-Mapper
A small client-side Fabric mod for Minecraft 26.1.2(needs fabric api 0.155.3+26.1.2).  Pick two corners and it walks a "lawnmower" sweep over the whole rectangle between them. useful for large map downloads, Needs Elytra Fly to works 

# Important
recommended to use ElytraFly (meteor client) instead of fireworks
source code is only available for the version  v1.5.0
made using Claude Sonnet 5.5

# Commands

```text
/autopilot a "1st corner"
/autopilot b "2nd corner"
/autopilot start
/autopilot stop
/autopilot spacing
/autopilot status
/autopilot turnspeed
```

And on newer versions, old cmds + `/autopilot elytra true`
